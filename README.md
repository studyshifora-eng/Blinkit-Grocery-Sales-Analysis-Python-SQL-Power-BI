# Blinkit Grocery Sales Analysis | Python, SQL & Power BI

## Project Overview
An end-to-end data analysis project focused on evaluating grocery sales performance and outlet operations using Blinkit data.

The objective is to identify sales trends, understand product performance, and analyse how outlet characteristics influence overall sales performance through data cleaning, SQL analysis, Python visualisation, and Power BI reporting.

## Business Objectives
- Evaluate overall sales performance and key business KPIs.
- Analyse sales across different product categories.
- Compare sales performance by item fat content.
- Understand sales distribution across outlet locations and sizes.
- Evaluate outlet performance based on outlet type and establishment year.

## Project Workflow

### 1. Data Cleaning & Preparation
- Inspected dataset structure and data types.
- Standardised inconsistent Item Fat Content categories.
- Prepared the dataset for analysis.

### 2. Exploratory Data Analysis – Python
- Analysed overall sales distribution.
- Evaluated product category performance.
- Compared sales by fat content.
- Examined outlet location and size performance.
- Visualised sales trends using Matplotlib and Seaborn.

### 3. SQL Analysis
Developed SQL queries to perform:
- Total sales and average sales calculations.
- Average customer rating analysis.
- Sales aggregation by item type.
- Sales comparison by fat content.
- Outlet-level sales analysis.
- Sales contribution percentage by outlet size and location.
- Performance comparison across outlet types.

### 4. Power BI Dashboard
Created a Power BI report to present sales performance and outlet-level analysis through visual reporting.

## Key Findings
- **Product Performance:** Fruits and Vegetables generated the highest sales (178,124.08), followed closely by Snack Foods (175,433.92).
- **Outlet Location:** Tier 3 outlets recorded the highest sales at 472,133.03.
- **Outlet Size:** Medium-sized outlets contributed the highest sales at 507,895.73.
- **Outlet Type:** Supermarket Type 1 generated the highest sales at 787,549.89.
- **Product Segmentation:** Low Fat products accounted for more item records than Regular products after standardising the categories.
